## ✅ 已修复

### 1. API Key 曾硬编码在 `config.py`（高危）

早期版本第二个参数是**真实可用的 Key**：

```python
ZHIPU_API_KEY = os.getenv("ZHIPU_API_KEY", "<真实Key>")
```

两个问题：Key 一旦推到 Git 就永久泄露（删掉也能从历史翻出来）；Key 失效时静默走到 401，排查困难。

**修复**：改为从 `.env` 读取 + 缺失即抛 `RuntimeError`；`.env` 加入 `.gitignore`，仓库只提交 `.env.example`。
另外旧 commit 里含 Key，因当时从未 push 过，直接备份旧 `.git` 并重新 `git init` 重写了历史。

### 2. `requirements.txt` 版本与实测环境严重漂移

原文件锁的是 2024 年的版本（`langchain==0.2.7` 等），而 `.venv` 实际是
`langchain 1.4.8` / `streamlit 1.66.1` / `chromadb 1.5.9`……六个包全不一致。
别人 clone 后 `pip install` 会装到完全不同的依赖树，环境不可复现。

**修复**：按 Python 3.13.16 实测版本重写，并显式列出所有被代码直接 import 的包
（原先 `langchain-core` 等靠间接依赖带入）。测试依赖拆到 `requirements-dev.txt`。

### 3. 没有测试与评估集

Agent 说「改好了」时无法证伪，调切块参数 / top-k 全靠感觉。

**修复**：新增 `tests/`（`pytest` 纯单元测试 + 20 条「问题 → 标准答案」评估集），
CI 在每次 push 自动跑测试。详见 [上手与练习.md](上手与练习.md)。

### 4. 缺少跨会话项目约定

隐性知识（相对路径陷阱、禁止事项、启动方式）只存在于对话和人的记忆里。

**修复**：新增 `AGENTS.md`，把约定、硬性禁止、已知坑点固化；文档拆成主文档 + 分册按需加载。

### 5. 演示 PDF 的中文正文被截断（阻塞 RAG 效果）

`data/扫地机器人用户手册.pdf` 里实际只有 **33 个字符**（「型号 X」「尘盒每」「提示轮」），
手册正文全部丢失，导致所有 PDF 相关问答都答「未找到」——而文档里还写着「答 3 个月」，属于虚假验证示例。

根因是 `generate_samples.py` 用 fpdf2 的 `multi_cell` 写小节标题后没有复位光标；
fpdf2 默认 `new_x=XPos.RIGHT`，下一段正文从页面**右边缘**开始渲染，中文被裁掉。

**修复**：所有 `multi_cell` 显式传 `new_x=XPos.LMARGIN, new_y=YPos.NEXT`，重建后 PDF 有 160 字符。
新增 `test_load_pdf_contains_full_manual` 作为回归护栏，防止复发。

### 6. `force_rebuild=True` 会重复追加块

原判断 `if p.name in state: delete_by_source(...)`，但 force 模式下 `state` 被清空，
条件恒假 → 旧块不删就追加，3 个文件入库后集合里躺着 6 块。

**修复**：改为 `if force_rebuild or p.name in state`，重建后稳定为 3 块。

### 7. 密钥与版本不再依赖口头约定

**修复**：CI 在每次 push 跑 `pytest -q`（含本地密钥正则扫描）与 `gitleaks` 全历史扫描；
`pytest.ini` 把需真实 Key 的集成评估标为 `integration` 并默认跳过，CI 用 dummy Key 也能跑通。

## 🟠 中优先级（待处理）

### 8. `tools.py` 的工具描述是从服装项目复制来的

`rag_summarize` 的 docstring 写着「尺码、售后政策」，但 `agent_app.py` 是**扫地机器人**客服。
工具 docstring 是 LLM 判断「何时调用」的唯一依据，写着服装内容会让它在该调用时犹豫。
应改成「产品参数、使用说明、故障排查、保养维护」。

> 这个坑很典型：**复制代码时最容易漏改的是给 LLM 看的自然语言**，编译器不会报错。

### 9. PDF 的 `page` 元数据在切块时丢了

`loaders.load_pdf` 给每页打了 `page` 标记，但 `knowledge_base.build` 把多页
`"\n\n".join(...)` 拼成整篇后重新切块，`page` 就没了，只剩 `source`。
要做「引用第几页」需改成逐页切块，或把页码映射写进 chunk metadata。

> 已有一份**填好的规格**覆盖这个改造：
> `skills/backend-sdd/examples/spec-rag-citation.md`（含 Open Questions 示范）。
